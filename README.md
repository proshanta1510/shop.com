# দুর্গাপুর এন্টারপ্রাইজ — দোকান ম্যানেজমেন্ট

তিনটি ফাইল: `index.html` (পেজ), `style.css` (ডিজাইন), `app.js` (সব লজিক)। 

## GitHub Pages এ চালু করার ধাপ
1. github.com এ লগইন → **New repository** → নাম দিন (যেমন `dokan`) → **Public** → **Create**।
2. **Add file → Upload files** চেপে `index.html`, `style.css`, `app.js` তিনটি ফাইল টেনে ছাড়ুন → **Commit changes**।
3. **Settings → Pages** এ যান → *Source* এ **Deploy from a branch** → Branch: **main**, Folder: **/ (root)** → **Save**।
4. ১–২ মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/dokan/`।

## মনে রাখবেন
- ডাটা প্রতিটি **ব্রাউজারের নিজের মেমরিতে** থাকে (এক ডিভাইসের ডাটা অন্য ডিভাইসে যায় না)। নিয়মিত **সেটিংস → ব্যাকআপ** নিন।
- প্রথম লগইন: ইউজার `admin`, পাসওয়ার্ড `admin123` — লগইনের পরই পাসওয়ার্ড বদলান।
- বারকোড ও ভাউচারের QR এর জন্য ইন্টারনেট লাগে (cdnjs থেকে লাইব্রেরি আসে)।
- পাবলিক রিপো হলে কোডে কোনো গোপন তথ্য (পাসওয়ার্ড, ডাটা) রাখবেন না। ডাটা রিপোতে যায় না, শুধু কোড যায়।
